## System Overview

CogniMail is a self-hosted email security platform that combines:
- Real-time SMTP email reception
- Multi-layered threat detection (ML, SpamAssassin, anomaly detection)
- Decision fusion engine
- Quarantine management
- Role-based access control
- Threat analytics and reporting
